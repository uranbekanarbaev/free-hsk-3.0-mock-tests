## How to download and start

1. Click the **ZIP** link next to your level.
2. Open Downloads and **unzip/extract** the file. On Windows, right-click → **Extract All**. On macOS, double-click the ZIP. On a phone, use the Files app's unzip/extract action.
3. Open the extracted folder. Double-click **`start.html`** for a simple page with the paper and audio. Or open **`test.pdf`** and play **`listening.mp3`** separately.
4. Print **`practice-answer-sheet.pdf`**, or use blank paper.
5. Follow the paper and audio. Open **`answers.pdf`** after finishing.

![Illustrated GitHub download guide](assets/how-to-download.svg)

If a PDF opens instead of downloading, use the viewer's download button. If GitHub shows a file page, use the downward arrow labelled **Download raw file**. If audio plays in the browser, use its download menu or choose the ZIP pack instead. You do not need Git, an account or the “Fork” button.

## Check your answers usefully

Use the supplied key for objective questions. Note both the answer and the reason for each mistake. Writing, speaking and translation require judgement: reference answers are examples, and a teacher can help assess acceptable alternatives. **Do not convert a raw percentage into an official HSK score or claim it predicts a pass.**

For a first session: finish the paper → check it → choose three weak areas → practise those → revisit the missed questions later.

## New HSK mock test FAQ

### Where can I download a free new HSK practice test with answers?

Choose a level in the [download table](#download-free-hsk-practice-tests-by-level). Each ZIP contains the new HSK sample paper, the answer key, complete listening audio and a personal practice sheet. Extract the ZIP and open `start.html` or `test.pdf`. No account is needed.

### Are these HSK 3.0 papers or old HSK 2.0 tests?

These packs contain the **new HSK 3.0 sample set** supplied with this project and linked from the official ChineseTest HSK 3.0 menu. Levels 1–6 have separate papers; levels 7–9 share one advanced examination. For example, the supplied new HSK 2 paper includes listening, reading and writing. [Source and file details](SOURCES.md).

### How many different mock exams are included?

There are **seven main sample papers**: one each for HSK 1, 2, 3, 4, 5 and 6, plus one shared HSK 7–9 paper. Levels 3–6 also include separate speaking samples. Different file formats and downloads are the same sample, not additional unique exams.

### Can I take the test offline or on my phone?

Yes. Download and extract a level ZIP, then open the PDF and MP3 in your usual apps. The included `start.html` offers an offline start page in browsers that support local HTML. On phones that do not open local HTML, use the PDF and MP3 directly. Print the practice sheet or write answers on blank paper.

### Is the answer key enough to calculate an official HSK score?

No. The answer key lets you check objective questions and review reference responses. A raw percentage is a practice result, not an official scaled HSK score or a pass prediction. Writing, speaking and translation require judgement; a teacher can help review acceptable responses.
